# 吉比特游戏研发工程师笔试专项

入口 `/quiz/#/topics/gbits`，侧栏“吉比特笔试专项”。42 道新增题（gbits-001–042）结合原有题，以稳定 legacy ID 定义专题，不移动原分类或复制旧题。静态总题数 220。

## 立即开始

先做起步 6 题（约 30 分钟），再练 C++、代码阅读、算法母题、客户端设计。混合练习卷是 20 选择、4 填空、2 编程，手动 90 分钟计时，逐题提交后可看解析。计时是练习辅助，离开/刷新后重置，不是正式考试/整卷自动判分。客观题自动判；多选按全匹配。算法无在线编译器，提交代码后自评并复测，评分仍由人决定。

## 来源

用户提供 `space-2.html`、`吉比特客户端方向备考清单.html` 和 `吉比特程序岗笔试题目汇总.html`，研究日期 2026-10-13。前两份完全相同，去重。历史题意改写、回忆题训练改写与考点训练变式均逐题标明；选项、约束、样例和解答为本次训练编写，不声称为官方真题。历史卷及登录核验事实来自附件，本次未重复登录核验。

技术解答参考 C++ 标准草案、TCP RFC 9293、MySQL 8.4、OSTEP 与 Unity 官方文档。代码用 C++17。原回忆中缺失的怪物规则、注册错误优先级、图形范围等均在题面注明补充。积木推倒、小图游览、三维共线不强行还原；数据分析与低可信常识未纳入核心。
