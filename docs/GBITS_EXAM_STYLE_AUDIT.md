## 对组卷的实际影响

1. 不能把20+4+2说成多年统一结构。保留一张2023式短综合卷；第二张采用2024回忆的16+2+3；第三张采用24+4+3的训练裁剪，融合2018的较长客观区块与2025的三编程配置，但明确不是2025原卷题量。
2. 三卷仍共78新题，但组成改为60单选、10填空、8编程；不为了保持旧草稿的“每卷26题”而忽视新证据。
3. 补C基础/类型与指针、字符串、循环轨迹、位运算/整数算法识别、概率组合/模周期、调度和手算树/堆。现代C++与图形预测只是适量补充，不称历年高频。
4. 已有题库的筛法、最大间隔、逆向资源DP继续作为可选定向复习；新卷以实质变式补齐，而非把用户可能做过的原题再搬一遍。三维几何先以规范向量计算短题覆盖，不凭缺图恢复原题。
5. A/B优先、C加练；38/40旧分组与现有记录不改；题型锁定模拟仍按通知规则设计。不同题量由卷元数据驱动，不能硬编码三个区块的题数。
