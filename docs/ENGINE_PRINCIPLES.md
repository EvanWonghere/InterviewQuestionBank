# 引擎原理练习索引

每次只选一个机制，先解释输入/状态/输出，再说明可观察现象。以下题目都可在题库按ID或“引擎原理”标签检索。

| 层次 | 题目 | 训练重点 |
|---|---|---|
| 运行循环 | q-167 PlayerLoop、q-168固定步 | 谁调用脚本；模拟与显示节奏 |
| 对象模型 | q-169假null、q-171序列化对象图 | 托管/本机身份，内联值与共享引用 |
| 资源与场景 | q-170 GUID、q-172激活门、q-173依赖引用 | 身份、状态机、所有权 |
| 渲染前端 | q-174 SRP Batcher、q-177提交管线 | CPU准备、绘制与GPU执行 |
| 数据与并行 | q-175 Transform缓存、q-176 Job依赖 | 失效传播与读写依赖 |
| 物理 | q-178粗筛/精测/求解 | 候选对、接触与响应 |

建议先做167、169、172、174；随后按实际项目涉及的机制选题。每题提供评分点、反例、最小验证和官方来源。不要把自己设计的缓存方案说成已证实的Unity源码实现，也不要把Profiler中的现象夸大成跨平台保证。

两周安排中以它们替换部分概念短块，不增加总工时；工程/实验题可以拆成20分钟子目标，未运行过的实验必须标明“待验证”。
